1. 页面生成
生成基于纯前端页面进行演示，使用白色为主色调加以其它炫酷颜色，
以粉红色为点缀，多一些图形效果，只要有演示的效果即可，
其它网页细节可以忽略，要求1000行以上代码

2. 动画效果
对文件进行动画效果的精细化优化，要求实现页面中所有功能模块及其包含的
小元素按预设顺序依次出现的动画效果。具体实施要求如下：
1. 为页面中各大功能模块建立明确的层级动画关系，确保父模块与子元素的动画衔接自然
2. 按相同精细度标准，为页面其他功能模块设计并实现类似的有序动画序列
3. 确保所有动画效果具有统一的时间曲线和过渡节奏，避免视觉混乱
4. 动画持续时间、延迟时间和过渡效果应保持一致的设计语言

3. 3D 效果
为该动画添加3D效果
4. PPT 风格
现要求将每个独立功能模块(模块名称)配置为独占一个完整页面。
实现一个轮播图（PPT）形式的页面切换机制，使各个模块页面能够按照预设顺序
自动轮流播放。系统应包含以下核心功能：
1) 模块页面独立渲染机制，确保每个模块拥有完整的页面空间
2) 轮播控制功能，支持自动播放/暂停、手动上一页/下一页切换
3) 轮播参数配置，可自定义切换动画效果、切换间隔时间、过渡时长
4) 响应式设计，确保在不同设备上均能完整展示模块内容并保持轮播功能正常运行
